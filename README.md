## 一、女仆能干什么（19 个工作模式）

### 采集类（会自动寻路找目标）

| 模式 | 做什么 | 需要 |
|---|---|---|
| 伐木 | 找原木砍掉并收集 | 主手**斧** |
| 挖沙子 / 挖沙砾 / 挖泥土 / 挖粘土 | 找对应方块挖掉 | 主手**锹** |
| 挖矿 | 挖**格雷矿石**，产出**原矿** | 主手**镐**（格雷硬锤也兼作镐）|
| 取水 / 取岩浆 | 用水桶装流体 | 背包**空桶** |
| 植树 | 在泥土/草方块上种树苗 | 背包**树苗** |

### 机器类（走到格雷机器旁作业）

| 模式 | 做什么 | 需要 |
|---|---|---|
| 维护机器 | 给未贴胶带的维护仓贴上胶带 | 背包**胶带** |
| 物流 | 把格雷机器的产出搬进自己背包 | — |
| 发电 | 用女仆自身经验给机器充电 | — |
| 洗矿 | 在装水的炼药锅里洗净粉碎矿 | 背包**粉碎矿** + 装水的炼药锅 |
| 添水 | 给炼药锅加水 | 背包**水桶** |

### 加工类（原地不动，只处理女仆背包）

| 模式 | 需要的格雷工具 | 转换内容 |
|---|---|---|
| 锤 | Hard Hammer（硬锤）| 原矿→粉碎矿 · 粉碎矿→含杂粉 · **锭×3→板×2** · 棒×2→长棒 |
| 锉 | File（锉刀）| 锭→棒 · 螺栓→螺丝 |
| 锯 | Saw（锯）| 长棒→棒×2 · 棒→螺栓×2 |
| 剪 | Wire Cutter（剪线钳）| 板→单线×2 · 螺丝→螺栓 · 棒→螺栓×4 |
| 研磨 | Mortar（研钵）| 锭→粉 |

## 三、安装

1. 把 `gtmaid-<版本>.jar` 放进 `mods/`
2. 确认格雷与车万女仆已安装
3. 配置文件：`config/gtmaid-common.toml`

## 四、使用要点

- **采集类 / 机器类**：必须给女仆**开 Home 模式并设置工作范围**，否则她只在主人 8 格内活动
- **所有任务**：需要的物品放在**女仆主手或背包**（空手右键女仆打开界面）
- 女仆**休息时间**或**坐着娱乐**时不会干活
- 工作模式在女仆界面的**任务列表**里切换
- 加工类**原地不动**，不需要 Home 模式

## 五、已知问题与未移植的功能

### 未移植（原版有，但在 1.20.1 / GTCEu 上无法或不应保留）

| 功能 | 原因 |
|---|---|
| 剪：「箔 → 细线」 | GTCEu 没有这个手工配方（只有线材轧机）|
| 锤：「洗净粉碎矿 → 纯净粉」「离心粉碎矿 → 粉」 | GTCEu 的锤子配方没有这两步（需离心机 / 研磨机）|
| 锤：「棒 → 环」 | GTCEu 锤配方没有（需弯曲机）|
| 配置项 `runDelayOre` / `runDelayTree` / `runDelayBroke` | 1.20.1 的检测节流由车万女仆接管，**这三项已失效** |
| 配置项 `oreMode`（矿辞模式） | 1.20.1 没有矿辞（OreDictionary）体系 |

### 已知行为差异

- **洗矿**用前缀转换实现，不校验格雷配方与电路板 → 比格雷机器宽松
- **维护机器**直接标记为已贴胶带，不检查是否真有故障 → 可能给无故障的仓贴胶带（消耗胶带）
- **发电**受机器输入电压 / 电流上限约束（原版无上限）
- **研磨**不再限制金属种类，只要该材料有粉形态即可
- 女仆经验从 NBT 标签 `MaidExperience` 读取，若车万女仆改动标签名会读到 0 → 此时每次只给少量 EU，仍可工作
- **没有任务专属动画**（使用车万女仆通用的挥手动作）
- 开发针对 **GTCEu 7.5.3**；其他 7.x 小版本理论上兼容，但若格雷改动过 API 可能出现 `NoSuchMethodError`

### 已验证 / 未验证

| 状态 | 模式 |
|---|---|
| ✅ **实机验证通过** | 挖沙子 · 挖泥土 · 锤 · 挖矿 |
| ⬜ 代码已审查、但**未逐项实机测试** | 挖沙砾 · 挖粘土 · 伐木 · 锉 · 锯 · 剪 · 研磨 · 取水 · 取岩浆 · 添水 · 洗矿 · 植树 · 维护机器 · 物流 · 发电 |

> 未验证不代表不能用 —— 挖沙砾 / 挖粘土 / 伐木与已通过的挖沙子共用同一套代码，锉 / 锯 / 剪 / 研磨与已通过的「锤」共用同一个类。

## 六、遇到问题怎么反馈

**唯一渠道：本仓库 Issues**（见上方【重要声明】第 3 条）

提交时请务必附上：

1. **哪个工作模式**（中文名，例如「洗矿」）
2. **现象**：女仆站着不动 / 有动作但没结果 / 游戏崩溃 / 其他
3. **女仆当时状态**：主手拿什么、背包有什么、有没有开 Home 模式、是否休息时间
4. **日志**：`logs/latest.log`（崩溃再加 `crash-reports/` 里的文件）—— 直接拖进 issue 输入框
5. **版本号**：gtmaid / gtceu / touhou_little_maid / Forge

### 提交前先自查（很多"像 bug"其实是用法）

| 现象 | 常见原因 |
|---|---|
| 女仆不动 | 没开 Home 模式，或目标超出主人 8 格 |
| 走过去但不干活 | 工具类型不对（挖矿要镐、伐木要斧、挖掘要锹）|
| 加工类完全没反应 | 材料不够（**格雷配方是 3 锭→2 板**，给 1~2 个不会动手）|
| 挖矿不挖某块矿石 | 只认**格雷矿石**，原版煤矿石不触发 |
| 发电几乎不涨 | 女仆经验低时每次只给少量 EU，属正常 |
| 洗矿/添水找不到锅 | 需要**装水的炼药锅** |

## 七、从源码构建

1. 需要 **JDK 17**
2. 把依赖 jar 放进 `libs/`（**因授权原因不随仓库分发**，清单见 [libs/README.md](libs/README.md)）
3. 构建：

```bash
./gradlew build
```

产物在 `build/libs/gtmaid-<版本>.jar`
